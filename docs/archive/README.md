# Historical archive — not active instructions

This directory preserves superseded snapshots and provenance from the v0.2.95 source tar. Its contents are intentionally excluded from the default AI reading path.

- `releases/`: 59 earlier per-increment release notes. The active release note v0.2.95 remains at repository root.
- `audits/firmware/`: 59 earlier firmware audits. The active v0.2.95 audit remains in `docs/`.
- `context/`: superseded working memory, context, critical and unverified documents copied from the source snapshot. These may contain stale facts and duplicated state.
- `patches/`: applied/historical patches and helper scripts retained for provenance. **Do not rerun them against the current tree.**
- `tooling/`: environment-specific historical instructions.

Historical records preserve what was documented at the time, not necessarily what is true now. When investigating history, compare the relevant release/audit against current source and the active decision ledger. Archive presence does not grant decision authority.
