# SF2 historical archive

This directory contains superseded development audits, prior design revisions and old sequencing notes. Do not treat these files as current specifications or first-read context. The active navigation and current model status are in `../INDEX.md` and `../README.md`.

- `audits/`: historical SF2 development audits.
- `design-revisions/`: superseded reviewer-evidence design drafts.
- `context/`: prior sequencing notes retained for provenance.
