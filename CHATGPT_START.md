# AI session starter

This file is retained for compatibility with older project instructions.
The canonical startup instructions are now in AI_START.md.

1. Give the agent exactly one codename: PISHDA, SHRU, QYUPAL or SEI.
2. The agent reads AGENTS.md, WORKING_MEMORY.md, index.md and
   AI_COORDINATION.md in that exact order in one batched read.
3. The agent discovers its role, current state, task routing and ownership
   from those files. Do not paste a separate project-history briefing.
4. Give one bounded task. When the instruction is "Continue", the agent uses
   the single next engineering task in WORKING_MEMORY.md.
5. Keep the latest accepted repository snapshot available. An archive upload
   does not synchronize other AI accounts, OpenCode, Claude or RDC workspaces.

## Session closeout

Record the baseline/snapshot, changed paths, exact verification commands and
results, what was not verified, open decisions, remaining risks, current
ownership state and the next single task. Update WORKING_MEMORY.md and
AI_COORDINATION.md only after checking the actual canonical repository.
Never claim production readiness without all applicable evidence.
